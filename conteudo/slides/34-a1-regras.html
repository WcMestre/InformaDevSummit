Assunto 1 · Regras

As três regras do padrão

Regras para a sala confirmar antes de votar.

  1. Release stable do mês termina em 0 — ex.: 27.1.0
  2. Hotfix incrementa o último número — 27.1.1, 27.1.2…
  3. A cada mês, uma nova stable — 27.2.0, 27.3.0, 27.4.0…
Como ler 27.N.H

27 é o ano.

N é a evolução da release stable, lançada todo mês.

H é o hotfix: sobe a cada hotfix e é 0 na release stable.
